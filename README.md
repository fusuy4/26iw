The Rating Files only contain topic level information, as to protect Reddit user privacy.

The Lexical Analysis Folder has all of the relevant files, along with the final outputs (ngram plots, summary statistics, preprocessing pipeline)

The Sentiment Analysis Folder contains a file used to collect Reddit data and tag it with sentiment form VADER and the fine-tuned roBERTa. The post_level and thread_level folder display the results of each level of analysis. 

The Topic Modeling Folder contains information of the reduced set of topics, their distribution, and the sentiment at the topic level. It also contains the script with the BERTopic pipeline. 

The Dataset Documentation contains information on the games used in the study. It also has the reduced topics, along with the test results of the LLM Prompting and human verification results.
